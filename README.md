# همیار ریاضی + بازی‌های یکپارچه

## فایل‌ها
- `index.html`: ساختار سایت و بخش بازی‌های ریاضی در همان نوار کناری
- `style.css`: ظاهر سایت اصلی به‌همراه سبک‌های بازی که فقط داخل بخش بازی اعمال می‌شوند
- `script.js`: منطق سایت و هر شش بازی؛ بدون فایل JavaScript اضافه

## اجرا
این چهار فایل را کنار پوشهٔ اصلی `assets` پروژه قرار بده و `index.html` را از طریق همان روش فعلی اجرای سایت باز کن. تمام فایل‌های فعلی `assets/icons` و `assets/fonts` خود سایت را نگه دار؛ این بسته عمداً دارایی‌های حجیم موجود سایت را دوباره کپی نمی‌کند.

## بازی‌ها
بخش «بازی‌های ریاضی» به نوار کناری اضافه شده است و از تنظیمات مشترک سایت برای حالت روشن/تاریک، تم رنگی، اندازهٔ نوشته، زبان و انیمیشن‌ها پیروی می‌کند. شش بازی دارد: سودوکو، پاسخ سریع، ادغام اعداد، معمای عددی، عدد گمشده و حافظهٔ ریاضی.

## محاسبه رنگ دیوار
ورودی‌های «تعداد دست رنگ» و «پوشش هر لیتر» حذف شده‌اند. برآورد داخلی با فرض تقریبی دو دست رنگ و ۱۰ متر مربع پوشش به‌ازای هر لیتر انجام می‌شود؛ نتیجه تخمینی است.

نکته: تشخیص نسخه دقیق سیستم‌عامل به اطلاعاتی بستگی دارد که مرورگر اجازه می‌دهد دریافت شود. اگر مرورگر نسخه را پنهان کند، سایت به‌جای حدس زدن، این محدودیت را نشان می‌دهد.
